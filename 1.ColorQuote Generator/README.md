# 📌 Interactive Quote Generator with Dynamic Background

## 🚀 Overview

This is a simple yet interactive web application built using **Vanilla JavaScript**.
It generates random motivational quotes on button click and changes the background color when the **Enter key** is pressed.

The project demonstrates core frontend concepts like **DOM manipulation** and **event handling**.

---

## ✨ Features

* 🎯 Generate random quotes on button click
* 🎨 Change background color using keyboard (Enter key)
* ⚡ Fast and lightweight (no libraries used)
* 🧠 Demonstrates JavaScript fundamentals

---

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript (Vanilla JS)

---

## 📂 Project Structure

```
project-folder/

```

---

## 🧪 How It Works

* A predefined array stores multiple quotes
* On button click → a random quote is displayed
* On pressing Enter key → background color changes randomly
* Uses `addEventListener` for handling events

---

## 📸 Demo Behavior

* Click button → New quote appears
* Press Enter → Background color changes
